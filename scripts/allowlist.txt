# Allowlist for scan_secrets.py

# One approved literal per line, followed by "#" and a REASON.
# A line without a reason is a configuration error and the scanner rejects it.
#
# Matching is normalised: everything that is not a letter or digit is stripped
# and the result is lowercased. So "+43 676 3437741" and "+43676343774 1"
# and "0043-676-3437741" do NOT all collide — only the exact digit sequence
# after stripping punctuation does. Write the number as it appears.
#
# RULE OF THUMB: allowlist a value only if it is already published by someone
# else (a hut's own website, an authority's contact page) or if you are
# deliberately choosing to disclose it. Never allowlist to silence a rule.
#
# NOTHING from the "lawsuit" rule may ever be listed here.
